# 当前适用口径与原样QA边界

本包只使用用户指定的第二版资料及最新注释；原文件中引用较早日期是来源元数据，不表示启用第一版要求。

- Agent context=environment/，Verifier context=tests/；只有Agent退出后才独立评分。选取真实目标版本支持的原生或有证据的适配profile，不把QA里较早示例的task-root复制规则照搬。
- 轨迹提交八字段；用户当前要求两条各至少10h、目标11h，不启用7h例外。即使原QA最低字段更宽松，也完整履行用户要求。
- 最终检查保留G01–G03、B01–B08、QA01–21、H01–06。QA15跳过不豁免资源实测；QA07/08只检查题面不等于物理隔离认证。
- supplied-qa 是原样复制，sources.json 记录哈希。默认实际入口 audit_task.py 会路由 implementation_review；不要因legacy分支的标题表而误读现行结果，也不要选择strict混入旧门槛。
- qa_runner 只是原样工具入口。collector首次结果不是语义终稿；先阅读规则和实际材料，写review，再复算生成。路径/版本不支持时明确未完成或提供真实适配证据，不改检查器制造通过。

原工具和我们新增工具测试通过只证明对应测试覆盖下的行为，不证明具体题目已被平台接受。
