# PCA 教学示例：从原包到三类交付

本题为非训练型群体遗传学 PCA：输入多样本 VCF，输出样本主成分，优化准确性约束下的 CPU 运行速度。Task ID：pca-teaching-format-example-20260929。S1/S2/S3 归类尚未由任务卡指定，annotation 对应值为 null。

本包用于说明目录、代码职责与执行流程，并不表示原 PCA 已符合教程的所有内容门槛。原生 Hidden 评分保留；公开 Starter 与 Dev 入口是本轮新增的教学变体，不能与原空白起步任务的历史成绩混用。

## 三、公开迭代怎么运行

Agent 镜像只从 environment/ 构建，不会 COPY tests/ 或 workspace/reference/。容器内公开区域 /workspace/starter、public_eval、public_assets 固定；可修改候选在 /workspace/solution。

原程序接口保持不变：

```bash
python /workspace/solution/pca input.vcf 3 output.tsv
python /workspace/public_eval/grader.py --submission /workspace/solution --repeats 3
```

每轮改变候选，运行相同公开命令，依据真实返回 JSON 判断。Dev 分数为每个 case 的 log2(基线中位时间/候选中位时间) 的均值，越高越好；每次重复均需满足子空间相似度≥0.98、输出格式/样本顺序/有限值/秩检查。失败 status 与 score=null 一起返回。每次候选调用30秒超时。

这只是公开代理指标：小数据、进程启动、缓存和运行顺序都会影响时间；不能保证 Hidden 排名与 Dev 一致，不能将其替代正式 native_reward 或长程优化证据。三组公开数据 seed 与哈希在 manifest.json，不能把它们当成三次独立训练/正式配对 seed。

轨迹的八个字段沿用教程，score 填真实 Dev 原始代理指标。保存最佳方法时，除了输出目录中的备份，结束前必须把最佳候选本身恢复到 /workspace/solution；否则 Harbor 会移交最后留在该目录的其他方法。

## 四、最终 Verifier 怎么运行

task.toml 明确：

```toml
artifacts = ["/workspace/solution"]

[verifier]
environment_mode = "separate"
timeout_sec = 10800
user = "root"
```

每次 Agent 运行结束后，平台复制最终候选到全新 Verifier 的 /workspace/solution，执行 bash /tests/test.sh。Verifier 自己生成/准备私有数据，使用 root 可信评分器和降权 chroot 候选执行边界，写 /logs/verifier/reward_detail.json 及原子写入的 reward.json。它不启动第二个 Coding Agent，也不自动为历史轮次补 Hidden 分数。

两侧均按原配置为8 CPU、16 GiB、32 GiB磁盘、0 GPU；Agent最长86400秒，Verifier最长10800秒，不代表已经实跑这些时长。构建时间预算分别1800/3600秒，运行期无网络。基础镜像python:3.12.8-slim-bookworm，numpy2.2.6、scipy1.15.3；Verifier另需Linux受限执行工具。

两套构建命令见包根 README。Verifier 构建期会下载SHA-256校验固定的约206 MB压缩真实数据并派生私有资产，评分时再生成合成套件。当前未构建镜像，因此实际镜像ID/digest均未填写；预期标签 pca-teaching-agent:local / pca-teaching-verifier:local 只是命令约定。

## 五、原生评分与教程差异

原生单数据集公式：accuracy × (0.10 + 0.90 × systems_unlock(accuracy) × time_quality) × method_factors；之后按类别聚合。准确性含子空间/群体结构检验；速度与可信完整扫描/快速参考对照；方法因子检查数学定义与约束。

原生公式有 [0,1] 截断和分段，快速参考用于速度满分锚点，部分无效提交是failed/0。因此不符合统一模板的全部归一化/失败语义。正式化需要另行改评分合同、避免固定Reference处饱和并重新标定B/R/U、重跑证据；本包没有静默改公式，更没有拿README中的历史成绩填新模板。
